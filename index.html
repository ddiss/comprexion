Comprexion

Compress or extract local files using only your browser

Caution: do not trust random websites with your personal data! This site does not transmit any of your file data, but anyone could publish their own malicious version which does.

How it works: all modern web browsers support gzip compression. This website uses your browser to compress or decompress a local file. The result is provided back as a file "download", but file data never leaves your computer.
